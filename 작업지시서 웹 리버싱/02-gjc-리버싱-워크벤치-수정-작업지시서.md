# gjc 리버싱 워크벤치 수정 작업지시서 (v1.1)

## 1. 목표

v1 리뷰에서 발견된 문제들을 수정한다:
1. epub-translator급 설정 창 + 설정 영속화 (UI 줌 디폴트 70%)
2. 프론트 추출 엔진 재구현 ("몇 줄 나오다 멈춤" 해소)
3. 보안 하드닝 (admin 하드코딩, 무인증 API, SQL 로그)

## 2. 배경 (리뷰 요약)

- 추출 기능이 색상/폰트 7개 필드만 반환하고 끝남. 멈춘 게 아니라 구현이 거기까지였음.
- 원인: v1 지시서가 "web-cloner 스킬 호출"이라고 썼으나, **Electron 앱은 에이전트 스킬을 직접 호출할 수 없음**
  (스킬은 가재코드 세션 안에서만 동작). 아키텍처 제약을 간과한 지시서 문제 + 최소 스크래핑으로 때운 구현.
- UI 줌 미적용, admin/admin 하드코딩, admin API 무인증, SQL verbose 로그.

## 3. 수정 항목

### 3.1 설정 창 (필수)

epub-translator의 설정 모달을 기준으로 구현:

- 설정 항목:
  - UI 줌 비율: 50%–150% 조절 (슬라이더 또는 숫자 입력), **디폴트 70%**
  - 출력 폴더 경로 (기본값: `D:/FREE-GJC/output/scaffold_mall`)
  - 쇼핑몰 이름 기본값, Admin ID 기본값
- 영속화: 설정 변경 시 즉시 저장 (localStorage 또는 JSON 설정 파일).
  **앱을 닫았다 다시 열어도 이전 설정이 그대로 적용될 것.**
  줌은 시작 시 `webContents.setZoomFactor(저장된 값)`으로 적용.
- 설정 모달은 리사이즈 가능 + 크기 기억 (epub-translator 모달 패턴).

### 3.2 프론트 추출 엔진 재구현 (필수)

**아키텍처 결정:** Electron 앱에서 가재코드 스킬을 직접 호출하는 방식은 불가능하다.
따라서 추출 로직을 앱 내부에 구현한다. (CLI 서브프로세스 방식은 v1.1에서 제외.)

offscreen BrowserWindow를 활용해 아래 4개 항목을 추출:

1. **디자인 토큰**: 색상 팔레트 (사용 빈도순 상위 N개), 폰트 패밀리, 주요 간격/모서리 반경 값.
   기존처럼 Set 무작위 순서가 아니라 **빈도순 정렬**할 것.
2. **레이아웃 구조**: header/nav/main/section/footer 등 시맨틱 섹션 트리 (태그 + 클래스 + 깊이).
3. **컴포넌트 인벤토리**: 버튼, 폼, 카드, 테이블 등 인터랙티브 요소 목록과 개수.
4. **핵심 로직 요약**: 외부 스크립트 목록, 주요 이벤트 리스너(click/submit/input) 탐지 결과.

출력 스키마:
```json
{
  "tokens": { "colors": [], "fonts": [], "spacing": [] },
  "layout": { "sections": [] },
  "components": [],
  "scripts": [],
  "elementCount": 0
}
```

UX:
- 추출 진행 상황을 **단계별**로 로그 패널에 표시 ("색상 추출 중...", "레이아웃 분석 중..." 등).
- 결과 패널은 JSON 덤프가 아니라 **요약 + 펼치기** 형태 (토큰 요약 먼저, 상세는 접기/펼치기).

### 3.3 보안 하드닝 (필수)

- Admin 계정: 스캐폴딩 시 입력된 비밀번호를 **bcrypt로 해싱**해서 Admin 테이블에 시드.
  `admin/admin` 하드코딩 삭제. (`bcrypt`는 이미 dependencies에 있음 — 실제로 사용할 것.)
- Admin API (`/api/admin/*`)에 **JWT 인증 미들웨어** 적용. 토큰 없이 호출하면 401.
- `better-sqlite3`의 `verbose: console.log` 제거.

## 4. 제외 사항 (사용자 결정)

- 저작권 안내 문구: 개인 테스트 용도이므로 v1.1에서 제외한다.

## 5. 완료 기준 (자체 검증 후 보고)

- [ ] 설정 모달에서 UI 줌 조절 가능 (디폴트 70%), 앱 재시작 후에도 유지됨.
- [ ] 출력 폴더 등 설정값이 재시작 후에도 유지됨.
- [ ] URL 추출 시 4개 항목(토큰/레이아웃/컴포넌트/로직)이 단계별 로그와 함께 표시됨.
- [ ] 색상이 빈도순으로 정렬되어 반환됨.
- [ ] 생성된 몰의 admin 로그인이 bcrypt 해시로 동작함 (`admin/admin`으로 로그인 불가).
- [ ] 토큰 없이 `/api/admin/orders` 호출 시 401 반환됨.
- [ ] 콘솔에 SQL 쿼리 로그가 찍히지 않음.

## 6. 주의사항

- diagnose-first: 패치 전 원인 가설과 설명부터.
- 완료 보고 전에 위 체크리스트를 직접 실행해서 전부 확인한 뒤 보고할 것.
